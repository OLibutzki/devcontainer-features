# Egress allowlist for the dev container.
#
# One entry per line. A leading dot matches the domain and all its subdomains
# (.example.com covers api.example.com); a bare entry matches only that exact
# host. Applies to plain HTTP and to HTTPS, where it is matched against the
# hostname in the CONNECT request.
#
# Anything not listed here is unreachable. After editing, reload the policy:
#
#   docker compose -f .devcontainer/docker-compose.yml restart egress
#
# This file must never be empty — Squid refuses to start on an empty ACL file.

# --- Git and GitHub ----------------------------------------------------------
# HTTPS remotes only; the proxy does not tunnel SSH, so git@github.com will not
# work. .githubusercontent.com covers raw (the /release-notes changelog feed),
# objects, and the pkg-containers blob store that ghcr.io redirects to.
# CAUTION: .githubusercontent.com serves arbitrary user content (any repo/gist
# raw file), so like storage.googleapis.com it is an attacker-usable exfil/C2
# channel, not a narrow endpoint. See egress/README.md.
github.com
.githubusercontent.com
